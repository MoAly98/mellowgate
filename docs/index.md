# Mellowgate Documentation

Mellowgate provides gradient estimators, experiment orchestration, and analysis
helpers for discrete optimisation in JAX. The documentation focuses on the clean
API layer, showing how to define problems, pick estimators, and analyse results
without digging through implementation details.
